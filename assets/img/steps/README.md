# Step pictures

One AI-generated illustration per step, 1200×900 (4:3), flat style, label colours (u) #2e7d4f, (m) #2f5d8a, (g) #b23a3a. File names and descriptions are listed in `PICS` in `src/pages.py`. Drop a file in here with the listed name and rebuild: it appears on its step automatically, captioned "AI-generated illustration." A missing picture is simply left out (or shown as a placeholder with `DRAFT=1`).
